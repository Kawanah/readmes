# Kit etudiant - IA Product Design Sprint

Formation de Laetitia - Digital Campus

Ce dossier contient les fichiers a fournir aux etudiant.es pour travailler pendant les 3 jours du Sprint.

## Principe

Les documents sont separes par type d'usage :

- brief de depart ;
- corpus / dataset Discovery ;
- canvas de cadrage ;
- brief produit a finaliser en fin de J1 ;
- journal d'usage de l'IA ;
- build prompt pour J2 ;
- kit test utilisateur et case study pour J3.

## Point important

Le corpus est un support pedagogique synthetique construit pour l'exercice. Les groupes doivent l'utiliser comme matiere fournie pour le Sprint, sans presenter ces informations comme une recherche terrain reelle.

L'IA peut aider a analyser, structurer, reformuler et generer. Elle ne doit pas inventer de donnees absentes du corpus.
